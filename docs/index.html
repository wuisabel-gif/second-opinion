Agent-agnostic AI code review

Change the agent,
not the reviewer.

Line-level AI pull request review, packaged as one GitHub Action.

second-opinion reads your pull request diff, sends it to the model you choose — Anthropic, OpenAI, any OpenAI-compatible service, or your own webhook — and posts precise, line-level findings back on the PR. Written in Rust. No vendor lock-in.

Plug it into GitHub

Three steps, about two minutes. The only credential you provide is your provider key, stored as an encrypted GitHub secret — it never touches the workflow file or the repository.

01

Add your key

In the repository you want reviewed, go to Settings → Secrets and variables → Actions and create a secret named REVIEW_API_KEY containing your Anthropic or OpenAI API key.

That one secret is the entire login. The action authenticates with it on every run.

02

Add the workflow

Copy the file below to .github/workflows/review.yml in your repository. It triggers on pull requests and never checks out or executes PR code — the diff is treated as review input only.

03

Open a pull request

The reviewer posts a summary plus line-level findings as PR review comments. Repeat runs deduplicate against its earlier comments, so you only ever see what’s new.

.github/workflows/review.yml 
name: Second-Opinion

on:
  pull_request_target:
    types: [opened, synchronize, reopened]

permissions:
  contents: read
  pull-requests: write

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - name: Review pull request
        uses: wuisabel-gif/second-opinion@v0.3.1
        with:
          api-key: ${{ secrets.REVIEW_API_KEY }}
          provider: ${{ vars.REVIEW_PROVIDER || 'anthropic' }}
          model: ${{ vars.REVIEW_MODEL }}

Full configuration — webhook endpoints, consensus passes, vote thresholds — lives in examples/review.yml.

One reviewer,
any agent

Swap providers with a single repository variable — the review contract, comment format, and deduplication stay identical.

Anthropicdefault

Native Messages API. Set REVIEW_API_KEY to an Anthropic key and you’re done.

OpenAI

Responses API with structured JSON output. Set REVIEW_PROVIDER=openai-responses.

OpenAI-compatible

LiteLLM, vLLM, Ollama, cloud gateways — point REVIEW_BASE_URL at any chat-completions endpoint.

Webhook

Your own hosted or local agent. The action POSTs a normalized payload and reads back {summary, findings}. A dependency-free starter server ships in the repo.
